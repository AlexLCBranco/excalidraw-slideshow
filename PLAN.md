## Queued

Ideas raised so far, not yet asked for. Don't start one without the owner
asking.

1. **Open a board by double-clicking it in File Explorer.** Would need a
   small launcher registered as the `.excalidraw` handler that passes the
   path to the app.
2. **Page thumbnails.** A strip or grid to jump straight to page N.
3. **Remember the last page per board**, so reopening resumes where you were.

## Not being built

- Editing boards. Editing happens on excalidraw.com; this app only presents.
- Writing to board files, including adding frames. The owner's files are
  read-only to this app.
- Cloud hosting or sharing. It's a local tool.
