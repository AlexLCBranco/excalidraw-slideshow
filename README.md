# Excalidraw Slideshow

Presents any `.excalidraw` board as a slideshow. Use ← and → to change pages.

**To use it:** double-click `Start Slideshow.bat` (or the Desktop shortcut),
then click **Open board…**.

**For development:**

```bash
npm install
npm run dev
```

See [ARCHITECTURE.md](./ARCHITECTURE.md) for how pages are found.
